# Cierre del plan del ecosistema

Continuación autorizada: completar los pendientes verificables y publicar los cambios. Mantener ventas/datos de producción; no ejecutar cobros, devoluciones o avisos de prueba.

- [x] Contratos: gramaje/rendimiento explícitamente malformado falla; ausencias legacy compatibles; fixtures de los cuatro consumidores.
- [x] Lecturas: catálogo y listas administrativas completas, errores explícitos, sin métricas parciales.
- [x] Accesibilidad POS: diálogo modal con contención y restitución del foco.
- [x] Reversos manuales: registro explícito de devolución ya realizada, idempotencia, saldo documentado, historial inmutable y estados atómicos.
- [x] Devoluciones sucesivas proveedor: intención durable distinta de reintento, congelar solicitud y saldo de referencia, conciliar antes/después; nunca simular ni enviar devolución real de prueba.
- [x] Entrega técnica (firma/prueba física pendientes externos): revisar despliegues por SHA y HTTP/auth; Android release configurado, identidad existente conservada, artefacto y requisitos si falta firma/dispositivo.
- [x] Backups: exportación completa de aplicación y restauración aislada; verificar conteos/constraints/triggers/permisos; documentar cobertura de auth/storage.
- [x] Revisión, suites/builds, migraciones exactas, stage propio, push y CI remota de los cuatro proyectos aprobada.

Liquidaciones bancarias y pruebas físicas requieren fuentes reales del dueño. No fabricar importes, claves de firma o evidencia de instalación. Un flujo listo no equivale a una conciliación bancaria realizada.
